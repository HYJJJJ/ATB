    首次安装与运行位置

    桌面端在本机运行，网页由所连接的 ATB 服务运行。在源码根目录使用 Python 3.10–3.12 执行（使用已安装的 Python）：

    python modules/assistant/scripts/setup-local-tts.py

    安装完成后刷新检测即可。该安装只提供合成模型；语音识别需另行初始化。

    桌面小助手显示、语音总开关开启且对话模型已配置时，在本地监听麦克风。说出名字或短语并稍作停顿即可唤醒，也能接着说问题；无关语音不保存、不发送给对话API。主界面对话或助手朗读期间暂停待机唤醒。隐藏小助手或关闭此开关即停止待机监听；点击人物仍可开关语音对话。

    对话节奏与打断

    火山双向方式直接接收模型文字流；火山单向方式按短句依次合成，收到首段音频即播放。ChatTTS 按句接收文字并分块播放音频；Qwen3-TTS 标准语速下按短句输入，音频码边生成边解码播放，不等整句音频完成；调整语速时改为整句生成后播放。若第三方模型接口不支持流式回复，可关闭；不会自动重复请求。语音使用对话窗口当前所选模型；模型首字慢时，可在对话窗口切换更快的模型。耗时从本轮提交起累计，含网络与合成等待。

    声音需超过阈值并持续达到设置时间才会打断。小动静容易误触发时调高阈值或延长时间。百分比为麦克风信号强度，并非环境分贝；默认 10% / 0.5 秒，可按你的麦克风调整。

    开始语音对话后，回复期间继续监听；检测到持续的新说话会停止当前声音并接续下一轮，也可点击“打断并说话”。使用浏览器回声消除，外放较响时可能误触发，可关闭此开关或佩戴耳机。唤醒词在上方“语音唤醒”中设置。
