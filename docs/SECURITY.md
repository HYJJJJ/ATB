# 安全与数据

管理员账户与所有模块共用同一会话。共享配置位于 `data/platform/settings.json`，AI 密钥只在服务端保存，页面只接收是否已配置。Linux 数据目录使用 700、敏感文件 600；Windows 应限制数据目录访问权限。服务器管理员和运行账户仍可读取明文密钥，请使用独立受限账户运行服务。

发布包不含账户、设备身份、监控录像、截图、CA 私钥、SSH 凭据或个人 API 配置。备份 data/certs 时应按敏感数据管理。公开 RustDesk 公钥是客户端连接参数，不能代替被控电脑的访问密码和授权策略；获知公钥者仍可能使用自建服务，OSS 服务不提供 ATB 账户级访问隔离。

模块属于可信程序代码，拥有平台进程权限，不是沙箱插件。只安装可信来源模块。网页不提供上传模块、任意执行命令、任意启动本机可执行文件或管理 SSH 凭据的能力。

私有 CA 只用于自己的服务。先通过可信方式核对证书再安装，不能通过忽略所有证书错误解决正式连接问题。公网服务需要认证和 TLS，反向代理或 NAT 应只开放登记过的端口。

发现问题时请提交不含密码、令牌、私人监控画面或资产清单的复现；不要将敏感信息写入公开 issue。
