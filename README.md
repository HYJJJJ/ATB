# ATB · All The Best

ATB 是一个以桌面 AI 助手为中心的 Windows 本机工具平台，将语音对话、桌面小助手、摄像头监控和远程控制放在同一套界面里。账户、API 设置和私人数据保存在本机；摄像头模块可以单独连接远程服务。

## 主要功能

| 功能 | 当前支持 |
| --- | --- |
| 桌面小助手 | 鲸鱼娘透明置顶摆件、拖动定位、点击开始或结束语音、倾听/思考/说话动作、流式文字气泡、图片放大和快捷菜单；关闭主窗口后收进系统托盘 |
| 语音交流 | 本地 SenseVoice 语音识别；按助手名字或自定义短语唤醒，兼容中文同音和部分前后鼻音差异；角色化应答、语音打断和告别后结束对话 |
| 语音合成 | 本地 ChatTTS / Qwen3-TTS，或火山引擎在线合成；支持流式音频播放、模型驻留复用、独立音色参数和试听；ChatTTS 提供 2646 组评分音色及自定义随机种子 |
| 角色与对话 | 多厂商 API 预设、Chat Completions / Responses、模型列表与切换；保存、切换和删除角色预设，内置小鲸鱼等不同聊天风格 |
| 记忆与主动交流 | 核心索引、私密日记、工作记忆三层结构，按条件稀缺写入、检索和自动修剪；随机主动机会、免打扰和频率上限，允许助手什么都不做 |
| 实时工具 | DSH 统一执行天气、新闻、时间、余额、Bing/搜狗公开网页搜索、网页正文及链接读取；可管理自定义 MCP 和浏览器能力 |
| 本机操作 | 打开 ATB 页面和开始菜单应用；可选查看应用开放的 Windows 控件，确认后填写、点击或选择 |
| 记录与额度 | 桌面摆件、助手页面与本人后台语音共享近期文字记录，含失败原因；对话/语音额度分开显示，支持余额状态灯和近 24 小时余额减少估算 |
| FreeCamera | 手机摄像头、实时音视频、设备备注、自动重连、对讲、截图录像和可选本机人物检测；可部署独立百度网盘归档服务 |
| 人脸与问候 | 多组人脸增删改查、姓名和关系等资料录入、本人/访客区分、到场问候、日程和免打扰设置 |
| RustDesk | 自建服务地址、公钥与端口配置、状态检查，以及启动已安装的官方 Windows 客户端 |

功能入口、模型安装和详细边界见 [智能助手说明](modules/assistant/README.md)、[FreeCamera 说明](modules/freecamera/README.md) 和 [RustDesk 说明](modules/rustdesk/README.md)。

## 下载与运行

在仓库 Releases 下载同版本文件：

- `ATB-<版本>-Windows-x64-full.exe`：平台与三个模块，含人物检测模型。
- `ATB-<版本>-Windows-x64-core.exe`：纯平台，无模块和模型。
- `ATB-<版本>-source.zip`：对应版本源码；`SHA256SUMS` 用于核对下载文件。

首次运行创建本机管理员账户。私人配置、API 密钥、聊天、人脸资料和证书私钥不随程序发布。运行数据和程序分开保存；可用 `ATB_DATA_DIR` 指定数据目录，兼容 `FREECAMERA_DATA_DIR`。

语音识别及本地 TTS 的 Python 环境和权重需另外初始化，不包含在便携程序内；初始化步骤和第三方许可见 [助手说明](modules/assistant/README.md)。使用在线对话或火山合成时，需要自行填写对应服务商的 API 配置。

连接远程摄像头服务时，在摄像头模块填写 HTTPS 地址并导入该服务的公开根证书，再使用远程服务账户登录。平台和助手继续使用本机账户及数据。iPhone 摄像头网页需要 HTTPS、证书信任、摄像头/麦克风权限及前台运行。

## 从源码运行

需要 Node.js 22+；Windows 桌面构建需要 x64 环境。

```powershell
npm ci
npm ci --prefix modules/assistant
npm run setup:model
npm start
# 桌面模式
npm run desktop
```

也可以使用根目录 `Start-ATB.cmd` 或 `Start-ATB-Desktop.cmd`。桌面源码预览只运行当前源码。更新后请从系统托盘选择“退出 ATB”再启动；直接关闭主窗口只会隐藏。

```powershell
npm test
npm run check
```

本地语音环境、人脸模型及额外能力的初始化见各模块说明。构建和正式发布流程见 [发布说明](docs/RELEASING.md)。

## 模块与共享配置

`modules/<id>/module.json` 声明模块入口和能力。移走模块目录并重启后，其页面、API 和监听一并移除，私人数据保留；删除本机模块不会自动更改远程服务。

平台统一管理账户、服务器地址及默认 AI。助手可继承平台模型，或保存自己的 API 配置；切换厂商保留已保存的对应配置。API 密钥只返回已配置状态，不在界面回显。

详见 [模块契约](docs/MODULES.md)、[部署说明](docs/DEPLOYMENT.md) 和 [安全说明](docs/SECURITY.md)。

## 能力边界

- 搜索受网络、验证页面、结果相关性和动态网站限制。搜索摘要及抓取时间不代表新闻发布日期；没有可靠来源时应明确说查不到。浏览器 MCP 需要显式启用，不能绕过站点登录或验证。
- 对话 API 需要支持相应工具协议。工具有调用次数、时限和权限约束，不保证任何兼容服务商或网站都能正常工作。
- Windows 控件操作依赖目标应用开放可访问控件；微信实际发信、专门的微信接入、闹钟调度及独立备忘录尚未完成。
- 三层记忆按账户在本机保存，不是完整聊天档案或跨设备同步。近期显示记录最多 40 条；日记无应用内公开读取接口，但不防止本机磁盘权限持有者读取文件。
- Qwen3-TTS 按短句提前输入；标准语速生成中分块播放，调整语速时需整句处理。它不支持向同一次推理持续追加文字，首次加载及生成耗时受设备影响。
- 余额查询取决于厂商是否开放接口和权限；余额减少估算不是官方消费账单。火山账户余额使用独立账务凭据，不等于 TTS 资源包字符余量。
- 云端录像归档需单独部署和百度网盘授权，便携程序不会自动开通。人脸、唤醒和实体音频效果仍需结合自己的摄像头、麦克风和扬声器测试。
