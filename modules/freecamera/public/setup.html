首次连接 · 只需配置一次

让 iPhone 安全连接
监控服务。

请用 Safari 打开本页。安装本机生成的根证书后，网页才能获取摄像头权限。

  1. 下载根证书

    点击下方按钮，允许下载配置描述文件。

    下载 FreeCamera 根证书
  2. 安装描述文件

    打开「设置 → 已下载描述文件」。若没有此项，前往「设置 → 通用 → VPN 与设备管理」，选择 FreeCamera Local Root 并安装。

  3. 开启完全信任

    打开「设置 → 通用 → 关于本机 → 证书信任设置」，开启 FreeCamera Local Root 的「完全信任」。仅安装、未信任时无法使用摄像头。

  4. 打开摄像头

    回到 Safari 点击下方按钮。如果仍有证书警告，先检查上一步，不要跳过警告。

    打开 iPhone 摄像头页 ↗
