# 整点录像与百度网盘归档

此服务单独部署在 Linux 服务器，Windows 桌面包不自动启动、部署或配置归档服务。

## 能力

- 按北京时间整点切分 VP8/Opus WebM，一小时一个独立文件。启动、断流、方向变化及停机时保存实际时段短片。
- 默认普通网盘目录为 `/我的资源/视频/ATB/FreeCamera/YYYY年/MM月/DD日/`，跨午夜归开始日期。
- 文件名示例 `13：00：00——14：00：00.webm`。使用全角冒号以兼容网盘命名约束。
- 按浏览器实际呈现方向录制，并把北京时间烧录到画面。ffmpeg 仅重封装，不重新编码。
- OAuth 自动续期、持久队列、分块上传；核对远端路径、大小与可用校验信息后，才精确清理对应本地文件。
- 上传失败退避重试；容量保护暂停新录制，保留未备份文件。重名冲突不覆盖既有文件，旧队列保留原目的地。

## 安装

源码位于 `archive/`，部署模板位于 `deploy/`。先安装该独立服务的依赖、受支持的 Chromium 与 ffmpeg，按部署模板配置本机 HTTPS 服务地址、可信 CA、数据目录及私有凭据文件，再启动独立的 systemd 服务。

归档凭据仅允许回环只读信令，不能对讲、改设备或启用人物检测。百度 OAuth 凭据单独保管；Windows 可用 `scripts/authorize-baidu.ps1` 存入当前用户的 DPAPI 秘密目录，不能把 Windows 加密文件直接复制到 Linux 使用。所有地址、账号和授权均由部署者自行配置；源码及发行包不含现成凭据、私人服务器配置或录像。

## 边界与验证

手机网页仍需 HTTPS、权限和前台发送画面。服务器无法录制已经停止发送的媒体。多摄像头相同时段会产生重名冲突，需要独立目录规划；此版本不承诺无缝换段或无限容量。

自动测试覆盖整点/跨日、崩溃恢复、容量、上传失败、校验后清理、只读信令，以及受控 WebRTC 音视频。实际部署仍需单独验收浏览器、网盘权限、长期续期、手机后台限制与资源容量。

官方参考：Baidu Netdisk SDK（`baidu-netdisk/baidu-drive-sdk-go`）与百度网盘开放平台文档。
