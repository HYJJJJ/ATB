# 小智参考与 ATB 实现边界

本次审阅的是已下载的 xinnan-tech/xiaozhi-esp32-server 提交 `4b1a54a41c28112bc06b1ab605d2ba723f678ad3`，不是对最新主分支的保证。2026-11-12 尝试刷新上游时 GitHub 连接重置，未更新本地副本。

- `main/xiaozhi-server/core/providers/tts/edge.py`：EdgeTTS 音色、rate、volume、pitch；ATB 同样将这些参数传入 edge_tts.Communicate。采用原始服务参数，默认音量不额外增益，语速不允许 -100%。
- `main/xiaozhi-server/core/providers/memory/mem_local_short/mem_local_short.py`：把历史摘要和新增会话交给模型总结，独立模式保存到 data/.memory.yaml，按 role_id 隔离；query_memory 返回摘要，不是向量搜索。
- `core/connection.py`：结束会话时异步保存记忆；查询时把记忆交给对话提示。
- `core/providers/memory/mem0ai/mem0ai.py`：通过 Mem0 add/search 保存和查询用户相关记忆。`powermem` 是另一可选实现。不能把小智的全部记忆策略概括为单一方案。
- `core/utils/dialogue.py`：会话历史和记忆是两个部分；不能据此宣称小智已对所有长期在线会话严格限制 token。

ATB最初参考摘要方案；2026-11-14生产记忆已按用户要求改为核心索引、私密日记、轻量工作记忆。旧摘要文件保留、不自动灌入核心；真实原文与私密反思分离，日记只供内部工具，公开回复模型只接收已核实的来源摘录。当前参数、内部工具、额外模型调用预算与隐私边界见本模块README；下方历史记录不能当作当前记忆实现。

这次仅修改本地工作区，不部署远程实例、不上传 GitHub、不覆盖正式 0.7.0 包。后续明确要求发布时，再生成新版本源码与 full/core 包。

## 2026-11-12：湾湾小何接入

用户选择台湾女声方向后，增加火山引擎 V3 HTTP Chunked 合成，首个音色为湾湾小何。使用官方音色 ID `zh_female_wanwanxiaohe_moon_bigtts`，模型名称为 `seed-tts-1.0` 或对应并发版；没有把小何 2.0 当作同一个音色。API Key 与旧版 APP ID + Access Token 都可配置，凭据放在平台共享数据 `speech.volcengine`，前端只收到配置状态。

本地 SenseVoice/Silero 识别保持原有方式；湾湾小何的试听/消息朗读不启动 Python、不加载识别模型。语速、音量、音调按该服务的参数范围显示并校验，各服务分别保留设置。配置缺失或合成失败时明确提示，不回退成其他音色。网络合成受独占连接、心跳、取消和关闭流程管理。

已用协议样本测试合成参数、音频分片、错误响应、凭据隔离、停止取消和无进程连接过期；网页 HTTP 和桌面 IPC 的设置流程使用临时数据目录验证。后来本机已配置真实火山凭据，2026-11-12 最小请求返回403资源未授权；真实音色合成和物理播放仍未成功，详见最新README和CONTEXT，不能用旧的“未配置”结论代替当前状态。

## 2026-11-12：本地合成与句级低延迟

增加可选 Kokoro v1.1-zh/sherpa-onnx 本地开源合成，保留 EdgeTTS、火山云端服务。各服务独立保存音色/参数，默认保留用户当前提供方；本地缺模型明确报错，不换云端。识别和合成各自按需使用，试听不加载ASR，停止/切换/退出释放模型。

参考用户指定的低延迟经验文章，已实现在线模型可见文本流 → 有界分句 → 首句合成/播放，同时预取一份后续音频。支持Chat Completions/Responses及普通JSON兼容；不朗读reasoning/tool事件，错误/截断不记为成功对话，不自动重发付费请求。快速回复可以关闭；静音等待默认600ms，保留已有设置。本地Kokoro与EdgeTTS每句仍先得到完整WAV/MP3；火山当前使用下述四种接口和PCM块播放。当时尚无自动语音打断；2026-11-13已补齐，见下文。2026-11-14已加入桌面本地语音唤醒：默认跟随当前助手名字，可在TTS与语音页添加自定义短语；命中后先以当前音色播放按角色性格提前准备的简短应答，再开麦或处理同句问题，应答不进入聊天或记忆。短句准备使用当前角色和所选模型，不读取日记或历史，按账户/配置缓存、切角色更新；未准备好使用中性应答。具体待机开关、句首读音匹配、资源交接与计费边界见模块README。

界面显示从本轮提交起的累计识别/首文字/首音频/播放器开始时间。固定本地短句实测、安装与许可见README和 `LOCAL-TTS-LICENSES.md`；模型不纳入源码。本轮本地工作不等于新发行包或云端部署。

## 2026-11-12：火山四种原生合成方式

按用户提供的官方文档，支持WebSocket双向、WebSocket单向、HTTP Chunked、HTTP SSE四种可保存方式。双向把模型delta直接传入同轮会话；其余方式现按短句依次独立提交，共用PCM播放器，首句生成即可播放，四者都逐块输出PCM并由Web Audio连续播放。试听、消息朗读和语音对话共用所选方法。旧配置保持HTTP Chunked，不自动替换提供方、音色或密钥。

界面统一“模型名称”，同时显示官方名称/ID；`modelName`兼容旧`resourceId`，上游原生头`X-Api-Resource-Id`不改名。1.0/2.0目录音色联动；复刻模型仅接入已有授权Speaker ID，区分ICL2的标准/表现力增强版本，后者与TTS2可用语气指令；不实现训练或混音。

二进制会话事件、官方status_code、终止标志、截断、凭据脱敏、授权租约及退出清理有自动回归。网页和Electron桌面分别用本地模拟上游测试四接口→真实Web Audio调度，覆盖首块在响应结束前播放、取消后不播晚到音频、无ASR试听。此验证不等于付费账户授权或物理扬声器验收。一次真实固定“你好”请求仍返回403/45000030，保存配置未改。用户现用应用未重启，未打包、上传或部署。

## 2026-11-12：语音首页与共享记忆文档

语音圆球为默认首页，输入/输出由真实音频RMS驱动（系统语音回退仅提供状态）；文字记录可展开并随主内容滚动。长期记忆按用户确认在同一账户全部对话间共享，只读查看自动精简文档，不要求手动输入保存。既有固定内容保留只读兼容。摘要仍是有界分批增量整理，不是完整逐字档案/向量库；每轮先持久化待整理批次，失败和容量限制继续明确提示。对话模型与TTS设置独立保留。验证证据和范围见CONTEXT的本轮记录。

## 2026-11-13：自动打断与浮动文字记录

活动语音对话中默认允许说话打断，开关可保存。最新版本在“TTS 与语音”增加音量阈值（默认10%，范围2–40%）和持续时间（默认500ms，范围200–1500ms），是麦克风RMS而非环境分贝；安静间隔达100ms清除累积，避免分隔杂音相加。超过阈值并持续达标才取消旧模型、合成与播放，保留麦克风和起音，在后端lease替换时缓存新句再识别；手动打断继续可用。属于轻量能量门控，不加载额外模型，持续大噪声/外放回声仍可能误触发；不是唤醒词或说话人识别。新默认值已用固定录音与真实本地SenseVoice/Kokoro在网页HTTP、桌面IPC验证第二轮识别播放及停止释放，模型文字流为隔离夹具，测试静音，不证明物理扬声器回声效果。

文字记录现为只读的右侧紧凑柔边浮层，已删除手动输入框/发送入口，仅显示语音与回复记录；语音组整体左移，窄屏下置。显示隐藏有动画，关闭即退出焦点顺序，减少动态可用；长记录隐藏内滚动条并支持边缘滚轮继续页面。
